# 0090 — Auteur frontend foundation, direction gate

The owner requested Auteur from https://github.com/agiwhitelist/auteur using npx skills add, then a newly derived platform covering the entire frontend, based on our existing work. The skill was installed at the workspace skill root and read in this session.

This is a system redesign, not a Blue polish pass. All existing frontend surfaces are in scope: public sports/search/live/favorites, match detail/research, login/signup/recovery/social, wallet, account/history/devices/limits, betslip/quote review/receipt, gated terminal/catalog/player/originals, admin and help. The functional Next.js/Python/session/feed/payment contracts are the reuse seam.

Auteur requires system and commit sheets before markup and a rendered mockup approved before implementation. Those artifacts and a proposed daylight Sports desk direction are in design/auteur/. This prototype is intentionally separate from shipping React code and labels all sample data; no financial actions occur. Only the direction gate is complete enough to review. Full integration and full implementation QA remain pending owner approval of this concrete direction.

The proposal uses white/silver surfaces, vermilion state/action roles and local Archivo/Source Sans 3. The comparison board and contextual research desk replace paired highlight banners. A bounded moodboard informed value contrast and asymmetrical information hierarchy; its images are excluded from Git and never used as product assets.

Local review: http://localhost:8770/mockup.html. No production deploy.
