# React Bits integration

SpotlightCard is adapted from React Bits:
https://github.com/DavidHDev/react-bits/tree/main/src/content/Components/SpotlightCard

The inherited implementation adds proximity, keyboard focus, smoothing and
reduced-motion support. Its surfaces and borders use the storefront CSS theme
variables. Casino carousel and sports hero content remain ordinary interactive
HTML; decorative layers never intercept clicks. No animation dependency is
required. License terms are preserved in LICENSE.md.
