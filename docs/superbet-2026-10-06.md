# Superbet capture analysis — 2026-10-06

Status: **blocked at the edge; everything below the redirect chain was not
reachable from this operator's network.** What follows records the two
things this session actually verified about how the platform behaves, and
the capture checklist the same scripts unlock once the games page is
reachable (BR egress).

## Verified

1. **Traffic policy**: every path of `superbet.bet.br` issues a 302 to
   `https://brasilsembets.gov.br/`, a federal domain that serves the
   regulator-authored block landing. `superbet.com.br` is no longer in
   public DNS. So the operator's web tier and, presumably, its API tier
   gate on region/account-expiry — there is no public games endpoint to
   scrape without egress that is not blocked.
2. **Block-page stack**: the landing is GovBR design-system (`@govbr-ds/core`,
   Rawline font) under Cloudflare's `cdn-cgi/challenge-platform` challenge
   (JSD + oneshot XHR). Cost after the challenge: one favicon-scaled SVG
   logo, one denunciation banner, one federal signature image, one CSS
   bundle. No app JS, no player catalog, no odds calls, no WebSocket
   frame.
